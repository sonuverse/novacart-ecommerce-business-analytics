# NovaCart: E-commerce Business Analytics

## Overview
An end-to-end Python analytics project exploring revenue patterns, product associations, customer segmentation, and customer retention for a fictional direct-to-consumer (D2C) e-commerce business.

## Business Objectives
- Analyse revenue trends, seasonality, and potential anomalies.
- Identify product associations and potential bundle opportunities.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Evaluate customer retention using cohort analysis.

## Analytical Workstreams
1. **Time-Series Analysis:** Revenue trends, seasonal decomposition, and anomaly detection.
2. **Market Basket Analysis:** Frequent itemsets and association rules using the Apriori algorithm.
3. **RFM Customer Segmentation:** Customer scoring and segment-based insights.
4. **Cohort Retention Analysis:** Cohort-based customer retention patterns.

## Tools & Technologies

## Repository Contents
- `nova_cart_business_analysis.ipynb` — analysis, code, and visualizations.

## How to Run
1. Install Python.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the notebook in VS Code or Jupyter Notebook.
4. Run the notebook cells from top to bottom.

## Data Disclaimer
NovaCart is a fictional business. The data is synthetically generated, and the results are illustrative rather than actual company performance.
